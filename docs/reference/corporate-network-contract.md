# Corporate Network Contract

DevCrew Corporate fails closed for outbound network access:

```text
not declared -> not allowed
not configured -> disabled
```

Administrator-configured endpoints never fall back to legacy Orca or DevCrew public services. A missing or invalid endpoint disables that feature until the administrator supplies a valid destination.

## Categories

`automatic-app-owned-egress`

Network traffic generated by the app without an immediate explicit user action. Examples include telemetry, updater checks, cloud refresh, plugin refresh, provider polling, model metadata/download, and feedback backend calls. Corporate default is disabled. The normal lifecycle (`cold-start`, `focus`, `hide`, `show`, `restore`, `open-settings`, `open-support-feedback-ui`, `idle`) has expected automatic Internet egress of `0`.

`provider-specific-egress`

Traffic required by an explicitly allowed and enabled AI provider during an actual provider operation. Credential presence alone does not grant permission. The current Corporate baseline can allow Claude and Codex, but only when the provider is allowed, enabled, and invoked.

`user-initiated-egress`

Traffic attributable to an explicit user action, such as SCM operations, opening a browser URL, opening an issue tracker, or using a configured marketplace. The initiating action must remain attributable in the `initiatedBy` field.

`administrator-configured-egress`

Traffic to deployment-configured endpoints such as plugin marketplace sources, plugin kill-list endpoints, issue/support URLs, artifact services, approved SCM hosts, future browser allowlists, and internal services. Missing configuration disables the feature; it does not fall back.

`forbidden-legacy-implicit-dependency`

Legacy/public Orca infrastructure is never a Corporate runtime default. The shared contract also denies representative legacy public destinations such as `*.onorca.dev`, `github.com/stablyai/orca`, `github.com/stablyai/orca-plugins`, PostHog, and legacy social/support URLs.

## Decision Model

The inspectable model lives in `src/shared/network/corporate-network-contract.ts`.

`CorporateNetworkIntent` records:

- `source`
- `category`
- `capability`
- `destination`
- `initiatedBy`
- optional provider state

`CorporateNetworkDecision` returns:

- `status`: `allow`, `deny`, or `disabled`
- `reason`
- `category`
- source/capability/destination metadata

Endpoint resolution follows:

```text
Corporate configuration
        |
valid explicit endpoint?
   yes -> use configured endpoint
   no  -> feature disabled
```

The contract is intentionally not a firewall/proxy implementation. It is the policy vocabulary and deterministic decision surface for #90 endpoint remediation, #91 static forbidden-endpoint scanning, and #92 runtime egress tests.
