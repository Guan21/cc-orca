# G2-B5c Task C implementation plan

**Goal:** Compose existing Main authorization, HEAD receipt and synchronous G1 delivery contracts offline, without installing production inputs or a sender.

**Architecture:** A default-disabled Main-only adapter consumes the existing B3 authority `run()` (including reauthentication and one-use grant), Task B provider, a Main registered-binding reader and a mock-only fact loader. It requires explicit readiness and a subscription for every lifecycle domain. Invalidation synchronously cancels work, invalidates provider receipts and retires authority before a mutation is published. It never selects or grants authority.

**Tech stack:** TypeScript, existing Main classes, Vitest. No new dependency.

## Design decisions

Reuse the B3 authority rather than duplicate Electron authentication or instantiate a parallel grant registry. Reuse the Task B provider's private receipts and Task A fence rather than accept caller-built HEAD evidence. Keep the adapter uninstalled rather than modify production refresh/bootstrap: actual principal, credential custody, immutable registration, HEAD and ACL inputs remain absent and approvals remain blocked.
